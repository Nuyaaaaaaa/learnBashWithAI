# Курс Bash / командная строка (Git Bash)

База для фронтендера: навигация, создание файлов, копирование, просмотр.  
Без этого Git («создай файл и закоммить») ощущается тяжелее.

## Где практиковать

Уроки 01–04 — только в:

```text
learn-bash/sandbox/
```

Финальный босс — в `final-boss/work/` (создаёшь сам по ТЗ).

`sandbox/` не коммитится в репу курса (см. `.gitignore`). Результат босса (`final-boss/work/`) можно закоммитить.

## Подготовка

```bash
cd learn-bash
mkdir -p sandbox
cd sandbox
pwd
```

## Порядок обучения

Имеет смысл: **bash → git → js**.  
Если в Git путаешь `mkdir` / `touch` — начни отсюда, потом возвращайся в [learn-git](../learn-git/).

## Шпаргалка клавиш (коротко)

| Клавиша | Зачем |
|---------|--------|
| `↑` / `↓` | предыдущая / следующая команда |
| `Tab` | дописать путь или команду |
| `Ctrl + A` | в начало строки |
| `Ctrl + E` | в конец строки |
