# Практика: навигация

Работай в `learn-bash/sandbox/` через **Git Bash**.

## Задания

1. Перейди в sandbox и проверь, где ты:

```bash
cd learn-bash/sandbox
pwd
ls
```

2. Создай учебную папку и зайди в неё (создание — тема 02, но для навигации ок):

```bash
mkdir demo-nav
cd demo-nav
pwd
```

3. Поднимись на уровень выше:

```bash
cd ..
pwd
```

4. Сходи «домой» и вернись в sandbox (путь подставь свой из `pwd` в шаге 1):

```bash
cd ~
pwd
cd -    # вернуться в предыдущую папку (удобный трюк)
```

Если `cd -` не сработал — просто `cd` по полному пути снова в `learn-bash/sandbox`.

## Ожидаемый результат

Ты всегда можешь ответить: «я в такой-то папке» (`pwd`) и перечислить, что в ней (`ls`).
