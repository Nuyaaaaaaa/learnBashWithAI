# 01 — Навигация

## Урок

Терминал всегда «стоит» в какой-то папке. Команды работают относительно неё.

```bash
pwd          # print working directory — где я сейчас
ls           # list — какие файлы и папки здесь
ls -la       # подробнее (в т.ч. скрытые)
```

Переход:

```bash
cd имя-папки           # внутрь
cd first/html          # сразу на несколько уровней
cd ..                  # на уровень выше
cd ~                   # домой (в Git Bash на Windows часто /c/Users/ТвоёИмя)
```

`~` у тебя **не** `/Users/stas_basov` из чужой шпаргалки — проверь своим `cd ~` и `pwd`.
