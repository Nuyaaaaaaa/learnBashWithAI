# 03 — Копировать, перенести, цепочки

## Урок

```bash
cp файл.txt папка/              # копировать файл в папку
cp a.html b.html backup/        # несколько источников → папка
mv файл.txt папка/              # переместить (или переименовать)
mv old-name.html new-name.html  # переименование — тоже mv
```

Цепочка команд: следующая запустится, **если предыдущая успешна**:

```bash
mkdir simple && cd simple && touch index.html style.css
```

Удобно для быстрого старта каркаса. Для учёбы сначала делай шаги по одной команде, потом собирай в `&&`.

Связка с Git (напоминание, полный курс — в learn-git):

```bash
mkdir simple && cd simple && touch index.html style.css && git init
```
