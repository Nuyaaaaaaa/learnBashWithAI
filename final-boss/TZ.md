# ТЗ: Nuya Landing — разложить проект

**Роль:** frontend-разработчик  
**Задача:** собрать каркас папок и файлов **только из Git Bash**  
**Стек команд:** `pwd`, `ls`, `cd`, `mkdir`, `touch`, `echo`, `cat`, `cp`, `mv`, `&&`

Представь: в чат кинули «разложи пустой лендинг по нормальной структуре до конца дня».

---

## Итоговая цель

Примерно такая структура (имена важны):

```text
final-boss/work/
  REPORT.md
  nuya-landing/
    index.html
    script.js
    README.md
    css/
      styles.css
    images/          # пустая папка ок
    backup/
      index-copy.html
      styles.css     # копия
    docs/
      notes.txt
```

Точные имена в backup можно чуть варьировать, если смысл тот же: есть копии и переименование.

---

## Этап 1 — Рабочая зона и проект

1. Открой Git Bash в `learn-bash` (или зайди туда через `cd`).
2. Создай `final-boss/work/nuya-landing`.
3. Зайди в `nuya-landing`, проверь `pwd` и `ls`.

Критерий: ты внутри пустой (почти) папки проекта, путь содержит `nuya-landing`.

---

## Этап 2 — Каркас файлов

В корне `nuya-landing` создай пустые файлы:

- `index.html`
- `styles.css`
- `script.js`

Критерий: `ls` показывает все три.

---

## Этап 3 — Папки и перенос стилей

1. Создай папки `css/` и `images/`.
2. Перенеси `styles.css` в `css/styles.css` через `mv`.
3. `index.html` и `script.js` оставь в корне проекта.

Критерий: `ls` и `ls css` подтверждают раскладку.

---

## Этап 4 — README через терминал

1. Создай `README.md` командами `echo` / `>>` (2–3 строки: что за проект).
2. Проверь содержимое: `cat -n README.md`.

Критерий: файл читается в терминале, строки на месте.

---

## Этап 5 — Бэкап

1. Создай папку `backup/` внутри `nuya-landing`.
2. Скопируй туда `index.html` и `css/styles.css`.

Критерий: в `backup/` лежат копии (исходники на местах).

---

## Этап 6 — Переименование в backup

Внутри `backup/` переименуй скопированный `index.html` в `index-copy.html` (`mv`).

Критерий: `ls backup` показывает `index-copy.html`.

---

## Этап 7 — Цепочка `&&`

Одной строкой (через `&&`) создай папку `docs` и файл `docs/notes.txt`.

Критерий: после одной команды-цепочки оба существуют.

---

## Этап 8 — Отчёт

В `final-boss/work/REPORT.md` (рядом с папкой `nuya-landing`, не обязательно внутри неё) напиши своими словами:

1. Какие команды использовал на каждом этапе (кратко).
2. Чем `cp` отличается от `mv`.
3. Зачем нужен `pwd` перед кучей команд.
4. Итоговое дерево проекта словами или списком.

Файл можно создать через `touch` + Cursor или через `echo`.

---

## Этап 9 — Remote (опционально)

Из корня `learn-bash`:

```bash
git status
git add final-boss
git commit -m "пройти финального босса bash"
git push
```

Если remote уже настроен — этого достаточно. Без push этап всё равно засчитывается при живом `work/` + `REPORT.md`.
