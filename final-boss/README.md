# Финальный босс Bash

Контрольная «как на работе»: тимлид просит разложить каркас фронт-проекта.  
Готовых «напиши `mkdir`» нет — сам выбираешь команды Git Bash.

## Когда проходить

После тем **01–04**. Sandbox уроков не трогай — босс отдельно.

## Где работать

```text
learn-bash/final-boss/work/
```

Папку `work/` и проект внутри создаёшь **сам через терминал** (это часть задания).

## Порядок

1. Прочитай [TZ.md](TZ.md) целиком.
2. При необходимости сверяйся с [WALKTHROUGH.md](WALKTHROUGH.md).
3. Git Bash → выполняй этапы по порядку.
4. Если застрял >15 минут — [hints.md](hints.md).
5. Отметь [checklist.md](checklist.md). Можно написать: «проверь bash-босса».

## Правила

- Только Git Bash (не Проводник для создания папок/файлов босса).
- Код в HTML можно не верстать — важна **структура** и команды.
- Не используй `rm -r` вне своей `work/` / учебных папок.
- Vim не обязателен.
- В конце можно `commit` + `push` в репу `learn-bash` (опционально).
