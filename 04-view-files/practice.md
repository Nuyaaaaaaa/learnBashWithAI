# Практика: просмотр файлов

В `learn-bash/sandbox/`.

## Задания

1. Создай файл с текстом и прочитай его:

```bash
echo "строка один" > demo.txt
echo "строка два" >> demo.txt
cat demo.txt
cat -n demo.txt
```

`>` — записать файл заново, `>>` — дописать в конец.

2. (Опционально) Открой Vim и сразу выйди без сохранения — чтобы не бояться:

```bash
vim demo.txt
```

Потом: `Esc` → `:q!` → Enter.

3. Обычный путь для учёбы: открой `demo.txt` в Cursor и поправь текст там.

## Ожидаемый результат

Умеешь быстро посмотреть файл из терминала и не паникуешь, если открылся Vim.
