# 04 — Просмотр файлов (+ мини Vim)

## Урок

```bash
cat файл.txt        # показать содержимое в терминале
cat -n файл.txt     # то же + номера строк
```

Для вёрстки чаще удобнее открыть файл в Cursor. `cat` полезен быстро глянуть README или лог, не уходя из терминала.

### Vim (на будущее, не обязательно)

Иногда Git или система открывает Vim (например, длинное сообщение коммита). Минимум:

| Действие | Клавиши |
|----------|---------|
| Режим ввода текста | `i` |
| Выйти в командный режим | `Esc` |
| Выйти **без** сохранения | `Esc`, затем `:q!` и Enter |
| Сохранить и выйти | `Esc`, затем `:wq` и Enter |

В повседневной работе фронтендера можно почти не пользоваться Vim: пиши код в Cursor, коммиты с `-m "сообщение"`.
