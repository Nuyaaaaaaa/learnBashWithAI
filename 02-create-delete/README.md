# 02 — Создать и удалить

## Урок

```bash
mkdir second-project              # создать папку
touch index.html                  # создать пустой файл
touch index.html style.css app.js # несколько файлов через пробел
```

Удаление:

```bash
rm about.html              # удалить файл
rmdir images               # удалить пустую папку
rm -r second-project       # удалить папку со всем содержимым (осторожно!)
```

`rm` / `rm -r` **нельзя отменить** через Git, если файл не был закоммичен. В sandbox можно тренироваться; в боевых проектах — думай дважды.

Файлы удобно править в Cursor после `touch`. Не обязательно писать код через терминал.
